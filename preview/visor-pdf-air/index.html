    Cómo funciona este visor

    El documento lo dibuja el visor de PDF del propio navegador.

    1. Cambiar de página o de zoom vuelve a cargar el documento en la posición pedida.
    2. La página indicada es la última pedida desde estos controles; no cambia si te desplazas dentro del documento.
    3. No hay miniaturas: el navegador no las ofrece a la página, así que el panel lista las páginas por número.
